# ترجمة C++ إلى NeverC

ينتج الأمر التجريبي `neverc translate` شيفرة `.nc` قابلة للمراجعة عبر `cpp-core-v1` و`cpp-core-v2` و`cpp-project-v1` و`cpp-math-v1`.

**المتاح حالياً هو ترجمة شيفرة C++ فقط.** دعم E Language (易语言، `.e`) وPython وGo وRust وTypeScript وJavaScript ضمن الخطط المستقبلية؛ ولا تتوفر مترجمات لهذه اللغات بعد.

## الإعداد والترجمة الأساسية

استخدم تثبيت NeverC المعتاد مع موارده القياسية. الواجهة الأمامية لـ C++ وترويسات SDK المعتمدة مضمّنة فيه، ولا يلزم تثبيت Clang منفصلاً. راجع [ملاحظات بناء الواجهة الأمامية](../../utils/translate-frontends/cpp/README.md).

```sh
neverc translate --from cpp input.cpp -o output.nc
neverc output.nc -c -o output.o
```

يقبل الملف التعريفي `cpp-core-v1` ملف مصدر C++17 مستقلاً واحداً دون include. يدعم `int` و`unsigned int` و`bool` و`void` والأنواع التجميعية البسيطة والدوال غير الأعضاء ومساحات الأسماء والتحميل الزائد وتدفق التحكم الموثق. تُفحص جميع التصريحات في المدخلات، بما فيها الشيفرة غير المستخدمة.

اختر `--profile cpp-core-v2` لإضافة أسماء الأنواع البديلة `typedef`/`using` بعد التحقق منها، والتعدادات ذات الأنواع الصحيحة الأساسية المدعومة، و`static_assert`، ودعم محدود لمؤشرات الكائنات ومراجع القيم اليسرى. تحافظ المعاملات والنتائج المرجعية على ارتباطها بالكائن الأصلي، مع دعم المؤشرات الفارغة ومستويات `const` المتداخلة. تظل القيود مقتصرة على ملف مصدر واحد دون include. راجع [عقد core v2](../../utils/translate-frontends/docs/cpp-core-v2.md).

يضيف core v2 أيضاً المصفوفات المحلية ثابتة الحجم وحقول المصفوفات والفهرسة متعددة الأبعاد والمؤشرات والمراجع إلى المصفوفات. تملأ التهيئة الجزئية العناصر القياسية المحذوفة بالصفر، بينما تتبع عناصر البنية التهيئة المختارة وتحافظ على ترتيب التهيئة والارتباط بالتخزين الأصلي. توجد حدود للحجم ولتوسيع التهيئة. لا تزال المصفوفات العامة ومتغيرة الطول غير مدعومة.

يدعم core v2 عبارات `switch`/`case`/`default`، بما فيها عبارات التهيئة في C++17 والانتقال إلى الفرع التالي وتعليقات `[[fallthrough]]` التي جرى التحقق منها. يُقيَّم تعبير الاختيار مرة واحدة، وتُحفَظ وجهات `break`/`continue` داخل switch والحلقات المتداخلة. تُرفض نطاقات case الخاصة بـ GNU وسمات العبارات الأخرى.

يدعم core v2 الآن الأعداد الصحيحة الموقعة وغير الموقعة بعرض 8 و16 و32 و64 بت، وأنواع المحارف وقيمها الحرفية، واستعلامات `sizeof`/`alignof` الثابتة. تُجرى ترقيات الأعداد وحسم التحميل الزائد قبل توحيد العرض؛ وتتبع أنواع `long` و`wchar_t` ونوع الحجم منصة الهدف. تشمل أنواع أساس التعدادات أيضاً الأعداد الضيقة والواسعة. لا تزال سلاسل وقت التشغيل وSTL قيد التطوير.

يدعم core v2 أيضاً إزاحة مؤشرات الكائنات والفرق بينها وزيادتها وإنقاصها والإسناد المركب، بما يشمل اجتياز المصفوفات وخطوات المصفوفات متعددة الأبعاد. تحافظ الدوال المساعدة المولدة على قواعد C++17 لإضافة الصفر إلى المؤشر الفارغ أو طرحه منه وللفرق بين مؤشرين فارغين. لا تزال مقارنات ترتيب المؤشرات والتحويل بينها وبين الأعداد الصحيحة وحاويات STL وخوارزمياتها غير مدعومة.

يتحقق core v2 من أحجام الأنواع ومحاذاة ABI بمقارنتها مع نموذج الهدف الخاص بـ NeverC، بما في ذلك أحجام البنى وإزاحات الحقول. تعيد التأكيدات الثابتة في الشيفرة الناتجة التحقق من التخطيط عند الترجمة، ويسجل ملف البيان هذه البيانات.

يدعم Core v2 الدوال الأعضاء المسماة غير الافتراضية في أنواع البنية المقبولة، بما فيها تحميلات const الزائدة والطرق المقيّدة بـ lvalue والطرق الساكنة و`this`. تحافظ الاستدعاءات على هوية الكائن الأصلي وتقيّم الكائن المستقبِل قبل الوسائط.

يدعم Core v2 المنشئات العادية التي يعرّفها المستخدم لأنواع البنية ذات التخطيط القياسي وعمليات النسخ المدعومة. تُنشأ الكائنات المحلية والحقول وعناصر المصفوفات في مواضع التخزين النهائية، وتُهيّأ الحقول بترتيب التصريح. لا تزال المنشئات المفوّضة والاستثناءات غير مدعومة.

ينشئ Core v2 كائناً مستقلاً لكل معامل بنية يُمرّر بالقيمة، ويكتب النتيجة في موضع التخزين لدى المستدعي. تنطبق القواعد نفسها على المنشئات والدوال الأعضاء، مع الحفاظ على النسخ المطلوبة وارتباط المراجع بالكائنات الأصلية. قد تضيف تطبيقات C++17 الأخرى نسخاً للوسائط أو النتائج للأنواع البسيطة المستوفية للشروط.

يدعم Core v2 الهادمات العادية التي يعرّفها المستخدم وهدم الأعضاء الضمني عند الخروج الطبيعي. تُهدم الكائنات المحلية والحقول وعناصر المصفوفات بترتيب عكسي، والكائنات المؤقتة في نهاية التعبير الكامل بعد حفظ القيم المطلوبة. تنفّذ العودة والتفرعات والحلقات وbreak وcontinue التنظيف اللازم. تُهدم معاملات القيمة عند خروج الدالة المستدعاة، بينما يتولى المستدعي إدارة الكائنات المعادة. لا تزال استدعاءات الهادم الصريحة وهدم الكائنات الساكنة وفك المكدس بسبب الاستثناءات غير مدعومة.

ينفّذ Core v2 منشئات النسخ ومعاملات إسناد النسخ العادية التي يعرّفها المستخدم، بمعامل مصدر من النوع `R&` أو `const R&`. يستخدم النسخ الكائن الهدف الفعلي ويحافظ على الآثار الجانبية والمرجع المعاد. تقيّم صيغة الإسناد المعامل الأيمن أولاً، بينما يقيّم الاستدعاء الصريح لـ `operator=` الكائن المستقبِل أولاً.

يدعم Core v2 أيضاً المنشئات الافتراضية التي يولّدها المترجم أو تُعلن default، ودوال الهدم default، بما فيها أعضاء البنى والمصفوفات المتداخلة. يجري الإنشاء في الموضع الفعلي وبترتيب التصريح، ولا تصفّر تهيئة القيمة إلا ما تتطلبه قواعد C++. تُحفظ القواعد المختلفة لتعريف default خارج الصنف. لا يُشترط جسم دالة إضافي لمنشئ غير مستخدم أو وارد فقط في تعبير غير مقيّم.

يدعم Core v2 منشئات النسخ الضمنية والمعلنة صراحةً default، بما فيها البنى المتداخلة والمصفوفات متعددة الأبعاد. تُنفّذ منشئات نسخ الأعضاء المختارة في الموضع الفعلي وبترتيب التصريح والعناصر، ويُقيّم عنوان المصفوفة المصدر مرة واحدة. يحافظ النسخ البسيط على قيم المؤشرات المخزنة. يحفظ تمرير القيم والإرجاع من كائن مصدر آثار النسخ، ولا يضيف التمرير المباشر لـ prvalue نسخاً إضافية.

يدعم Core v2 أيضاً الإسناد بالنسخ الضمني أو المعلن صراحةً default. تحتفظ الأعضاء وعناصر المصفوفات بعمليات الإسناد المختارة وترتيبها؛ وتتحول نسخ المصفوفات البسيطة المولّدة إلى إسنادات عناصر ذات أنواع دون استدعاء خارجي لنسخ الذاكرة. يحافظ الإسناد البسيط على المؤشرات ويعيد الكائن المستقبِل الفعلي. تلتقط صيغة المعامل مرجع المصدر أولاً، والاستدعاء الصريح للعضو المستقبِل أولاً؛ ثم تُقرأ قيم المصدر بعد تلك الآثار. لا ينشئ الإسناد كائنات إضافية ولا يهدمها.

يدعم Core v2 مهيئات الأعضاء الافتراضية للحقول المقبولة، بما فيها الوصول إلى الأعضاء السابقة والاستدعاءات العادية والسجلات والمصفوفات المتداخلة. يستخدم المهيئ المختار كائنه الفعلي بوصفه `this`، بينما تحتفظ عناصر تهيئة التجميع الصريحة بقيمة `this` لدى المستدعي. تستبدل التهيئة الصريحة المهيئ الافتراضي لذلك العضو. لا يعيد النسخ والإسناد الضمنيان أو default تشغيل المهيئات؛ ويمكن لمنشئ النسخ المعرّف من المستخدم اختيارها للأعضاء المحذوفة من قائمته. تحتفظ تهيئة أعضاء المنشئ وتهيئة التجميع بحدود هدم الكائنات المؤقتة الخاصة بكل منهما. لا تزال القوالب ودعم STL الكامل قيد التطوير.

يدعم Core v2 مراجع rvalue إلى كائنات موجودة وحية، بما فيها الأسماء المستعارة للقيم العددية والمؤشرات والسجلات والمصفوفات، والمعاملات والنتائج المرجعية، وتعبيرات xvalue الشرطية والطرق العادية المؤهلة بـ `&&`. يحافظ `static_cast<R&&>(live)` على الكائن نفسه، وتبقى متغيرات مراجع rvalue المسماة من فئة lvalue. تتبع الأحمال الزائدة والنسخ القائم اختيار Clang. لا تضيف المراجع مسؤولية هدم جديدة.

ينفّذ Core v2 منشئات النقل وإسناد النقل العادية التي يعرّفها المستخدم من مصدر حي من نوع `R&&` أو `const R&&`. يستخدم الإنشاء موضع التخزين الفعلي، ويحافظ الإسناد على تعديلات المصدر وترتيب التقييم والمرجع `R&` المُعاد، بما في ذلك المستقبل المؤهل بـ `&` أو `&&`. تختار مراجع rvalue المسماة أحمال lvalue، وتحتفظ المنشئات الصريحة بقواعد تهيئتها. لا ينهي النقل عمر المصدر؛ ويُهدم المصدر والوجهة كالمعتاد.

يدعم Core v2 أيضًا إنشاء النقل وإسناده الضمنيين أو المعرّفين صراحةً بـ default، بما يشمل السجلات المتداخلة والمصفوفات متعددة الأبعاد. تنفّذ الأعضاء النسخ أو النقل الذي اختارته C++ بترتيب التصريح والعناصر. لا يعيد النقل المولّد تشغيل مهيئات الأعضاء الافتراضية، وتحافظ العمليات البسيطة على قيم المؤشرات المخزّنة. تُهدم المصادر كالمعتاد، ولا تحتاج العمليات المولّدة غير المستخدمة أو البسيطة إلى أجسام مختلقة. تحتفظ العمليات الضمنية البسيطة المضمنة سابقًا بسلوكها مع المؤقتات؛ ويظل ربط المراجع المؤقتة العام غير مدعوم. دعم C++ وSTL الكامل لا يزال قيد التطوير.

يدعم Core v2 تصريحات `noexcept` و`noexcept(true/false)` القياسية المحسومة و`throw()` في C++17، إضافة إلى استعلامات `noexcept(expression)` الثابتة. تراعي الاستعلامات مواصفات الدوال والهادمات المختارة دون تنفيذ معاملاتها. تظل جميع المعاملات والمواصفات المكتوبة خاضعة لفحص المصدر، بما فيها الشيفرة غير المستخدمة. لا يزال رمي الاستثناءات والتقاطها وفك المكدس والقوالب وSTL الكامل قيد التطوير.

يدعم Core v2 التحميل الزائد العادي للمعاملات كدوال أعضاء أو حرة، بما يشمل الحساب والمقارنة والفهرسة وفك الإشارة والزيادة والكائنات القابلة للاستدعاء وتواقيع الإسناد العامة. يحافظ على الدوال المختارة والمراجع المرتبطة بالكائنات ونتائج الكائنات. تتبع صيغة المعامل ترتيب C++17، وتقيّم المعاملات المنطقية المحمّلة الطرفين. تهيّئ دوال الإسناد الحرة المعاملات من اليمين إلى اليسار ثم تهدمها بالترتيب العكسي. لا تزال القوالب وتخصيص الذاكرة وSTL الكامل قيد التطوير.

يدعم Core v2 أيضاً دوال التحويل العادية للكائنات الحية: التحويلات الضمنية والصريحة للأعداد الصحيحة والتعدادات والمؤشرات، و`bool` الصريح في الشروط، والنتائج المرجعية أو الكائنية. يستدعي كل تحويل دالة العضو المختارة مرة واحدة. تحافظ المراجع على ارتباطها بالكائن الأصلي، وتهيّئ قيم الكائنات المؤقتة وجهتها الفعلية مباشرة. ويحتفظ تحويل المرجع إلى قيمة بعملية النسخ أو النقل المختارة. تتبع مؤهلات const والمراجع وconstexpr وnoexcept قواعد C++17. لا تزال أعمار المراجع المؤقتة والقوالب وSTL الكامل قيد التطوير.

يدعم Core v2 الآن الكائنات المؤقتة المستقبلة للاستدعاءات والوسائط المؤقتة العددية أو السجلية الممررة بالمرجع حتى نهاية التعبير الكامل، بما يشمل المنشئات والطرق والمعاملات والتحويلات. لكل تقييم موضع تخزين فعلي، وتحافظ نتائج الكائنات على وجهتها النهائية والمراجع على ارتباطاتها. بعد الاستدعاء وهدم معاملات الدالة، تُهدم المؤقتات بعكس ترتيب إنشائها، بما في ذلك الشروط وتكرارات الحلقات. تُدعَم المصفوفات الفرعية داخل السجلات المؤقتة. لا تزال المصفوفات المؤقتة المستقلة وإطالة العمر بالمراجع التلقائية أو الساكنة والقوالب وSTL الكامل قيد التطوير.

## المشروعات متعددة الملفات

اختر وحدات الترجمة صراحةً من قاعدة بيانات التجميع وحدد المجلد الجذري للمشروع. تحلل الواجهة الأمامية المضمّنة كل وحدة على حدة؛ ويتحقق الدمج من التعريفات والربط والأنواع المشتركة والالتزام بقاعدة التعريف الواحد (ODR) باستخدام فحوص محافظة.

```sh
neverc translate --from cpp --profile cpp-project-v1 \
  --project-root "$PWD" --compdb build/compile_commands.json \
  src/a.cpp src/b.cpp --out-dir generated
```

يتكون خرج المشروع من `translated.nc` و`translated.h`. لا تُقبل إلا ترويسات المشروع الواقعة داخل هذا المجلد الجذري. إذا كان للملف عدة إعدادات، فاختر فهرسه الذي يبدأ من الصفر باستخدام `--compdb-entry src/a.cpp=4`. تُحلل أوامر التجميع المحفوظة بوصفها بيانات ولا تُنفذ أبداً.

## دعم محدود للرياضيات بدقة مزدوجة

يضيف `cpp-math-v1` إلى المشروعات نوع `double` والتحويلات والمقارنات الموثقة والتوقيعين الدقيقين `std::fabs(double)` و`std::floor(double)`. يستخدم مجموعة ترويسات Clang 20.1.8 / libc++ 200100 / macOS 15.5 المضمّنة، ويتطلب تحديد هدف macOS 15.0 صراحةً (arm64 أو x86_64). لا تزال العمليات الحسابية العامة بالفاصلة العائمة غير مدعومة. يجب حجب مصائد الاستثناءات وتعطيل تحويل الأعداد دون الطبيعية إلى الصفر؛ اختُبرت أوضاع التقريب القياسية الأربعة.

```sh
neverc translate --from cpp --profile cpp-math-v1 \
  --target arm64-apple-macosx15.0.0 \
  --project-root "$PWD" --compdb build/compile_commands.json \
  src/math.cpp --out-dir generated-math
```

تتحقق الترجمة الرياضية أيضاً من ترويسات NeverC المثبتة وهوية التطبيقات المضمنة وتجري اختبار ربط فعلياً. تستخدم الوحدات المولدة بيئة تشغيل NeverC. مع `-fno-builtin-std` تفشل الترجمة قبل كتابة الملفات فقط إذا احتاجت الشيفرة النهائية إلى تعيينات `fabs`/`floor`. ويمكن مواصلة ترجمة الشيفرة الرياضية التي لا تحتاج إلى هذه التعيينات.

## التحقق والمخرجات

استخدم `--check` بدلاً من خيار إخراج لتنفيذ التحليل والتوليد وفحوص الصياغة وملف الكائن نفسها دون الاحتفاظ بالملفات المولدة. يكتب `--report PATH` تشخيصات منظمة. لا تشغّل عملية الترجمة البرنامج المصدر أبداً.

لا تُستبدل المخرجات أو الملفات الملحقة الموجودة. يتطلب `--out-dir` مجلداً جديداً داخل مجلد أب موجود؛ ويتطلب `-o` مسار `.nc` جديداً. يسجل البيان متطلبات الهدف وبصمات المدخلات والمخرجات وخطوات التجميع؛ وتربط خريطة المصدر الأسطر المولدة بمواضعها الأصلية.

تُسجَّل نتائج CI وفحوص التنفيذ والتثبيت والاختبارات المتخطاة لكل منصة على حدة. يظل macOS arm64 الأصلي وmacOS x86_64 عبر Rosetta بيئتين مختلفتين للتحقق. لا يشمل النطاق المعلن دعم C++/STL الكامل أو الاستثناءات أو القوالب أو السلاسل أو `std::vector`. راجع [مصفوفة الدعم](../../utils/translate-frontends/docs/support-matrix.md)، و[البروتوكول وقواعد الاستعادة](../../utils/translate-frontends/docs/protocol.md)، و[مثال المشروع](../../tests/neverc/Inputs/translate/cpp/project).
