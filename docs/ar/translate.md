# ترجمة C++ إلى NeverC

ينتج الأمر التجريبي `neverc translate` شيفرة `.nc` قابلة للمراجعة عبر `cpp-core-v1` و`cpp-core-v2` و`cpp-project-v1` و`cpp-math-v1`.

**المتاح حالياً هو ترجمة شيفرة C++ فقط.** دعم E Language (易语言، `.e`) وPython وGo وRust وTypeScript وJavaScript ضمن الخطط المستقبلية؛ ولا تتوفر مترجمات لهذه اللغات بعد.

تحتفظ تصريحات التخصص الجزئي بفحص وسائط القالب الأساسي، بما فيها نسخ متغيرات الأعضاء ذات الوسائط الداخلية التابعة. تُفحص مصادر أنواع المعاملات المحلولة حتى إن لم يُختَر التخصص. تحتفظ توسعات الحزم مجهولة الطول بالمقدمة المفحوصة والمصدر الفعلي دون افتراض مواقع للوسائط. وتحتفظ التخصصات الكاملة التابعة لمتغيرات الأعضاء بالفحوص نفسها. لا يزال دعم C++/STL الكامل غير مكتمل. [C++17](../../utils/translate-frontends/docs/cpp-core-v2.md#partial-declaration-source-checks).

الاحتفاظ بفحص الوسائط لا يجعل التخصيص الجزئي صالحًا تلقائيًا؛ يجب أن يكون أكثر تخصيصًا وأن تكون معاملاته قابلة للاستنتاج. تبقى أنماط الحزم غير الصالحة وتصريحات إنشاء النسخ باستخدام extern بعد تعريف إنشاء النسخة أخطاء C++ (`TR0202`).

يدعم Core v2 الأصناف العادية المتداخلة ذات الأسماء داخل الأصناف العامة المقبولة، ونسخها الملموسة وتخصصاتها الصريحة الخاصة. لا يضيف الجسم العادي مستوى لمعاملات القالب. تبقى الأجسام غير المستخدمة مؤجلة؛ وتحافظ الحقول المنشأة والدوال المختارة وقوالب الأعضاء والأعمار والتخزين الساكن العددي على المصدر والمالك الفعليين. يُفحص المؤهل المكتوب لكل توجيه إنشاء صريح، بما فيه extern والتكرار دون أثر إضافي. ما زالت الوراثة والتخصيص وC++/STL الكامل غير مكتملة. الإدخال المنفذ هو C++ فقط؛ E Language وPython مخططان. تُستخدم مكتبات Clang المدمجة دون برنامج Clang خارجي. تتطلب النتائج الأصلية CI لإصدار التنفيذ. [C++17](../../utils/translate-frontends/docs/cpp-core-v2.md#ordinary-nested-classes-in-generic-owners).

يدعم Core v2 قوالب متغيرات الأعضاء الساكنة العددية في السجلات ونسخ الأصناف المدعومة، مع الوسائط الافتراضية والحزم المحدودة والتخصصات الجزئية والكاملة والتعريفات خارج الصنف. تتشارك النسخ المتكافئة التخزين، وتحتفظ الوسائط الداخلية أو الخارجية المختلفة بكائنات مستقلة. تُقرأ قيم const غير inline التي فُحصت دون تخزين، لكن العناوين والمراجع المقيّمة تتطلب تعريفًا. تُحفظ فحوص مصادر التصريحات والتعريفات وآثار المستقبل وإتلاف الكائنات المؤقتة. تحتفظ التخصصات الكاملة داخل الأصناف الخارجية التابعة بمصادر التصريحات الأصلية والملموسة. تُفحص الوسائط والقيم الافتراضية وأنواع المعاملات المحسومة فورًا، وتُفحص المصادر التابعة بعد إنشاء النسخة. لم تكتمل أنواع النتائج الأخرى والتهيئة الديناميكية وC++/STL الكامل. تُستخدم مكتبات Clang المدمجة دون Clang خارجي. لغة الإدخال المنفذة هي C++ فقط، بينما E Language وPython وغيرها مخططة. يتطلب التحقق الأصلي CI لإصدار التنفيذ. [C++17](../../utils/translate-frontends/docs/cpp-core-v2.md#concrete-member-variable-templates).

يدعم Core v2 قوالب الأسماء البديلة للأعضاء في السجلات العادية بما فيها المتداخلة ونسخ قوالب الأصناف المدعومة. يمكن للقيم الافتراضية والحزم المحدودة استخدام معاملات الصنف الخارجية أو الاسم البديل الداخلية، مع فحص الوسائط ومصادر الأنواع المستبدلة كلٌّ في سياقه. تحافظ الأسماء البديلة على دلالات القيم والمراجع والمصفوفات والسجلات دون كائنات قوالب وقت التشغيل. تُفحص التعريفات غير التابعة حتى إن لم تُستخدم، وتبقى الأنواع التابعة مؤجلة إلى الاستبدال. تُستخدم مكتبات Clang المدمجة دون برنامج خارجي. يتطلب التحقق الأصلي CI لإصدار التنفيذ. لم يكتمل C++/STL الكامل؛ لغة الإدخال المنفذة هي C++ فقط، بينما E Language وPython وغيرها مخططة. [C++17](../../utils/translate-frontends/docs/cpp-core-v2.md#concrete-member-alias-templates).

يدعم Core v2 النسخ الملموسة لقوالب دوال الأعضاء في السجلات ونسخ قوالب الأصناف المدعومة، بما فيها الدوال المسماة والساكنة والعوامل والمنشئات والتحويلات والحزم المحدودة والقيم الافتراضية والتعريفات الخارجية والتخصصات. تحتفظ الوسائط الداخلية والخارجية بهويات مستقلة، وتتشارك الاستدعاءات المتكافئة الشيفرة والتخزين الساكن. تُفحص مصادر الاستدعاءات والافتراضيات المختارة والأجسام المنشأة وأعمار الكائنات. تستخدم الترجمة مكتبات Clang المدمجة دون تشغيل برنامج Clang خارجي. تتطلب النتائج الأصلية CI لإصدار التنفيذ. الوراثة والتخصيص وC++/STL الكامل لم تكتمل. لغة الإدخال المنفذة هي C++ فقط؛ وتبقى E Language وPython واللغات الأخرى مخططة. تُفحص مصادر المحددات الخارجية الملموسة في تصريحات قوالب الأعضاء حتى دون إنشاء جسم للدالة. [C++17](../../utils/translate-frontends/docs/cpp-core-v2.md#concrete-member-function-templates).

يدعم Core v2 قوالب المتغيرات ضمن نطاق الأسماء بنتائج صحيحة أو منطقية أو تعداد، بما فيها auto المستنتج والتخصصات الجزئية المختارة والتخصصات الكاملة والقيم الافتراضية وحزم الأنواع أو القيم العددية المحدودة. يمكن استخدام سمات C++17 في static_assert وif constexpr ووسائط القوالب. تتشارك النسخ المتكافئة كائن تخزين عام ذا نوع محدد، بينما تحتفظ النسخ المختلفة بقيم وعناوين مستقلة. لا تفرض استعلامات النوع الثابت تهيئة غير مستخدمة ولا تنشئ تخزينًا. تظل الوسائط والافتراضيات المختارة وأنواع التصريحات والتعريفات والمهيئات المنشأة خاضعة للفحص. لم تكتمل التهيئة الديناميكية وأنواع النتائج الأخرى ودعم C++/STL الكامل؛ ويعتمد التحقق الأصلي على CI الخاص بإصدار التنفيذ.

يمكن أن يبقى sizeof(T) أو alignof(T) المباشر في النوع المكتوب لمعامل غير نوعي بيانات تصريح عندما يكون T هو معامل النوع نفسه من القائمة ذاتها. تظل الاستبدالات المختارة بحاجة إلى أنواع ملموسة مفحوصة؛ ولا يشمل الاستثناء أشكال الاستعلام التابعة الأخرى. لا يوفر تصريح extern template وحده التعريف الملموس الذي يتطلبه عقد الترجمة الحالي للوحدة المغلقة.

يستخدم Core v2 قواعد تحليل قوالب C++17 القياسية على جميع الأهداف المدعومة، بما فيها Windows x64 وARM64. تُحلَّل تعريفات القوالب دون التحليل المؤجل الخاص بـ MSVC؛ وتظل تعريفات الإنشاء الصريح المكررة ومواصفات الاستثناء غير المتوافقة أخطاء لغوية. ولا تُنشأ أجسام القوالب المعتمدة غير المستخدمة إلا عند الحاجة. لا يعني ذلك اكتمال دعم C++/STL. ولا تزال التخصصات الصريحة للدوال تحتاج إلى تعريف خاص بها ضمن وحدة المصدر؛ وتكرار التصريحات وحده لا يوفر هذا التعريف.

يدعم Core v2 المتغيرات العامة القابلة للتعديل من أنواع الأعداد الصحيحة والقيم المنطقية والتعدادات ضمن نطاق مساحة الأسماء، مع التهيئة بالصفر أو بتهيئة ثابتة جرى التحقق منها بالكامل. تبقى مساحة التخزين والعنوان ثابتين بين الاستدعاءات؛ وتصل المراجع والمؤشرات والوسائط الافتراضية إلى المتغير نفسه. يجب أن يرتبط إعلان `extern` بتعريف في وحدة المصدر نفسها. تبقى المتغيرات العامة const للقراءة فقط. وتظل القيود الخاصة بالتهيئة الديناميكية والسجلات والمصفوفات والمؤشرات والمراجع العامة والتخزين المحلي للخيط والمتغيرات المحلية static سارية.

يدعم Core v2 حلقات `for` القائمة على النطاق في C++17 للمصفوفات الثابتة المدعومة والنطاقات المعرّفة في المصدر، مع استدعاءات `begin/end` المحسومة عبر الدوال الأعضاء أو ADL. تحتفظ متغيرات الحلقة بالقيمة أو بالمرجع، ومكررات السجلات، وأنواع النهاية المختلفة بقواعد الاستدعاء والعمر المعتادة. تتم تهيئة النطاق واستدعاء `begin/end` مرة واحدة؛ وتُدمّر كائنات كل تكرار قبل الزيادة أو الخروج، بما يشمل `continue` و`break` و`return`. أشكال قوالب الأصناف الأخرى والترويسات القياسية وحاويات STL والربط المنظم وعبارات تهيئة النطاق في C++20 خارج هذه الإضافة. يتطلب التحقق الأصلي CI لمراجعة التنفيذ.

يدعم Core v2 أعضاء البيانات الخاصة والمحمية في الأصناف ذات التخطيط القياسي التي تستوفي بقية القيود. يتحقق Clang المدمج من صلاحيات الوصول قبل الترجمة؛ وتستخدم الدوال والبواني ودوال الإنشاء والوسائط الافتراضية وعمليات النسخ والنقل المسموح بها مساحة التخزين ذات الأنواع نفسها. يظل الوصول الخارجي غير المسموح به تشخيصًا في C++. محددات الوصول قواعد للغة المصدر ولا توفر سرية أثناء التنفيذ. تبقى القيود على الأصناف غير القياسية ذات مستويات الوصول المختلطة، والصيغ التابعة غير المدعومة لقوالب الأصناف الصديقة، والوراثة، وأنواع الحقول غير المدعومة. تتطلب النتائج الأصلية CI لمراجعة التنفيذ.

## الإعداد والترجمة الأساسية

استخدم تثبيت NeverC المعتاد مع موارده القياسية. الواجهة الأمامية لـ C++ وترويسات SDK المعتمدة مضمّنة فيه، ولا يلزم تثبيت Clang منفصلاً. راجع [ملاحظات بناء الواجهة الأمامية](../../utils/translate-frontends/cpp/README.md).

```sh
neverc translate --from cpp input.cpp -o output.nc
neverc output.nc -c -o output.o
```

يقبل الملف التعريفي `cpp-core-v1` ملف مصدر C++17 مستقلاً واحداً دون include. يدعم `int` و`unsigned int` و`bool` و`void` والأنواع التجميعية البسيطة والدوال غير الأعضاء ومساحات الأسماء والتحميل الزائد وتدفق التحكم الموثق. تُفحص جميع التصريحات في المدخلات، بما فيها الشيفرة غير المستخدمة.

اختر `--profile cpp-core-v2` لإضافة أسماء الأنواع البديلة `typedef`/`using` بعد التحقق منها، والتعدادات ذات الأنواع الصحيحة الأساسية المدعومة، و`static_assert`، ودعم محدود لمؤشرات الكائنات ومراجع القيم اليسرى. تحافظ المعاملات والنتائج المرجعية على ارتباطها بالكائن الأصلي، مع دعم المؤشرات الفارغة ومستويات `const` المتداخلة. تظل القيود مقتصرة على ملف مصدر واحد دون include. راجع [عقد core v2](../../utils/translate-frontends/docs/cpp-core-v2.md).

يضيف core v2 أيضاً المصفوفات المحلية ثابتة الحجم وحقول المصفوفات والفهرسة متعددة الأبعاد والمؤشرات والمراجع إلى المصفوفات. تملأ التهيئة الجزئية العناصر القياسية المحذوفة بالصفر، بينما تتبع عناصر البنية التهيئة المختارة وتحافظ على ترتيب التهيئة والارتباط بالتخزين الأصلي. توجد حدود للحجم ولتوسيع التهيئة. لا تزال المصفوفات العامة ومتغيرة الطول غير مدعومة.

يدعم core v2 عبارات `switch`/`case`/`default`، بما فيها عبارات التهيئة في C++17 والانتقال إلى الفرع التالي وتعليقات `[[fallthrough]]` التي جرى التحقق منها. يُقيَّم تعبير الاختيار مرة واحدة، وتُحفَظ وجهات `break`/`continue` داخل switch والحلقات المتداخلة. تُرفض نطاقات case الخاصة بـ GNU وسمات العبارات الأخرى.

يدعم core v2 الآن الأعداد الصحيحة الموقعة وغير الموقعة بعرض 8 و16 و32 و64 بت، وأنواع المحارف وقيمها الحرفية، واستعلامات `sizeof`/`alignof` الثابتة. تُجرى ترقيات الأعداد وحسم التحميل الزائد قبل توحيد العرض؛ وتتبع أنواع `long` و`wchar_t` ونوع الحجم منصة الهدف. تشمل أنواع أساس التعدادات أيضاً الأعداد الضيقة والواسعة. لا تزال المكتبة القياسية قيد التطوير.

يدعم core v2 أيضاً إزاحة مؤشرات الكائنات والفرق بينها وزيادتها وإنقاصها والإسناد المركب، بما يشمل اجتياز المصفوفات وخطوات المصفوفات متعددة الأبعاد. تحافظ الدوال المساعدة المولدة على قواعد C++17 لإضافة الصفر إلى المؤشر الفارغ أو طرحه منه وللفرق بين مؤشرين فارغين. لا تزال مقارنات ترتيب المؤشرات والتحويل بينها وبين الأعداد الصحيحة وحاويات STL وخوارزمياتها غير مدعومة.

يتحقق core v2 من أحجام الأنواع ومحاذاة ABI بمقارنتها مع نموذج الهدف الخاص بـ NeverC، بما في ذلك أحجام البنى وإزاحات الحقول. تعيد التأكيدات الثابتة في الشيفرة الناتجة التحقق من التخطيط عند الترجمة، ويسجل ملف البيان هذه البيانات.

يدعم Core v2 الدوال الأعضاء المسماة غير الافتراضية في أنواع البنية المقبولة، بما فيها تحميلات const الزائدة والطرق المقيّدة بـ lvalue والطرق الساكنة و`this`. تحافظ الاستدعاءات على هوية الكائن الأصلي وتقيّم الكائن المستقبِل قبل الوسائط.

يدعم Core v2 المنشئات العادية التي يعرّفها المستخدم لأنواع البنية ذات التخطيط القياسي وعمليات النسخ المدعومة. تُنشأ الكائنات المحلية والحقول وعناصر المصفوفات في مواضع التخزين النهائية، وتُهيّأ الحقول بترتيب التصريح. لا يزال فك المكدس بسبب الاستثناءات غير مدعوم.

ينشئ Core v2 كائناً مستقلاً لكل معامل بنية يُمرّر بالقيمة، ويكتب النتيجة في موضع التخزين لدى المستدعي. تنطبق القواعد نفسها على المنشئات والدوال الأعضاء، مع الحفاظ على النسخ المطلوبة وارتباط المراجع بالكائنات الأصلية. قد تضيف تطبيقات C++17 الأخرى نسخاً للوسائط أو النتائج للأنواع البسيطة المستوفية للشروط.

يدعم Core v2 الهادمات العادية التي يعرّفها المستخدم وهدم الأعضاء الضمني عند الخروج الطبيعي. تُهدم الكائنات المحلية والحقول وعناصر المصفوفات بترتيب عكسي، والكائنات المؤقتة في نهاية التعبير الكامل بعد حفظ القيم المطلوبة. تنفّذ العودة والتفرعات والحلقات وbreak وcontinue التنظيف اللازم. تُهدم معاملات القيمة عند خروج الدالة المستدعاة، بينما يتولى المستدعي إدارة الكائنات المعادة. لا تزال استدعاءات الهادم الصريحة وهدم الكائنات الساكنة وفك المكدس بسبب الاستثناءات غير مدعومة.

ينفّذ Core v2 منشئات النسخ ومعاملات إسناد النسخ العادية التي يعرّفها المستخدم، بمعامل مصدر من النوع `R&` أو `const R&`. يستخدم النسخ الكائن الهدف الفعلي ويحافظ على الآثار الجانبية والمرجع المعاد. تقيّم صيغة الإسناد المعامل الأيمن أولاً، بينما يقيّم الاستدعاء الصريح لـ `operator=` الكائن المستقبِل أولاً.

يدعم Core v2 أيضاً المنشئات الافتراضية التي يولّدها المترجم أو تُعلن default، ودوال الهدم default، بما فيها أعضاء البنى والمصفوفات المتداخلة. يجري الإنشاء في الموضع الفعلي وبترتيب التصريح، ولا تصفّر تهيئة القيمة إلا ما تتطلبه قواعد C++. تُحفظ القواعد المختلفة لتعريف default خارج الصنف. لا يُشترط جسم دالة إضافي لمنشئ غير مستخدم أو وارد فقط في تعبير غير مقيّم.

يدعم Core v2 منشئات النسخ الضمنية والمعلنة صراحةً default، بما فيها البنى المتداخلة والمصفوفات متعددة الأبعاد. تُنفّذ منشئات نسخ الأعضاء المختارة في الموضع الفعلي وبترتيب التصريح والعناصر، ويُقيّم عنوان المصفوفة المصدر مرة واحدة. يحافظ النسخ البسيط على قيم المؤشرات المخزنة. يحفظ تمرير القيم والإرجاع من كائن مصدر آثار النسخ، ولا يضيف التمرير المباشر لـ prvalue نسخاً إضافية.

يدعم Core v2 أيضاً الإسناد بالنسخ الضمني أو المعلن صراحةً default. تحتفظ الأعضاء وعناصر المصفوفات بعمليات الإسناد المختارة وترتيبها؛ وتتحول نسخ المصفوفات البسيطة المولّدة إلى إسنادات عناصر ذات أنواع دون استدعاء خارجي لنسخ الذاكرة. يحافظ الإسناد البسيط على المؤشرات ويعيد الكائن المستقبِل الفعلي. تلتقط صيغة المعامل مرجع المصدر أولاً، والاستدعاء الصريح للعضو المستقبِل أولاً؛ ثم تُقرأ قيم المصدر بعد تلك الآثار. لا ينشئ الإسناد كائنات إضافية ولا يهدمها.

يدعم Core v2 مهيئات الأعضاء الافتراضية للحقول المقبولة، بما فيها الوصول إلى الأعضاء السابقة والاستدعاءات العادية والسجلات والمصفوفات المتداخلة. يستخدم المهيئ المختار كائنه الفعلي بوصفه `this`، بينما تحتفظ عناصر تهيئة التجميع الصريحة بقيمة `this` لدى المستدعي. تستبدل التهيئة الصريحة المهيئ الافتراضي لذلك العضو. لا يعيد النسخ والإسناد الضمنيان أو default تشغيل المهيئات؛ ويمكن لمنشئ النسخ المعرّف من المستخدم اختيارها للأعضاء المحذوفة من قائمته. تحتفظ تهيئة أعضاء المنشئ وتهيئة التجميع بحدود هدم الكائنات المؤقتة الخاصة بكل منهما. لا تزال القوالب ودعم STL الكامل قيد التطوير.

يدعم Core v2 مراجع rvalue إلى كائنات موجودة وحية، بما فيها الأسماء المستعارة للقيم العددية والمؤشرات والسجلات والمصفوفات، والمعاملات والنتائج المرجعية، وتعبيرات xvalue الشرطية والطرق العادية المؤهلة بـ `&&`. يحافظ `static_cast<R&&>(live)` على الكائن نفسه، وتبقى متغيرات مراجع rvalue المسماة من فئة lvalue. تتبع الأحمال الزائدة والنسخ القائم اختيار Clang. لا تضيف المراجع مسؤولية هدم جديدة.

ينفّذ Core v2 منشئات النقل وإسناد النقل العادية التي يعرّفها المستخدم من مصدر حي من نوع `R&&` أو `const R&&`. يستخدم الإنشاء موضع التخزين الفعلي، ويحافظ الإسناد على تعديلات المصدر وترتيب التقييم والمرجع `R&` المُعاد، بما في ذلك المستقبل المؤهل بـ `&` أو `&&`. تختار مراجع rvalue المسماة أحمال lvalue، وتحتفظ المنشئات الصريحة بقواعد تهيئتها. لا ينهي النقل عمر المصدر؛ ويُهدم المصدر والوجهة كالمعتاد.

يدعم Core v2 أيضًا إنشاء النقل وإسناده الضمنيين أو المعرّفين صراحةً بـ default، بما يشمل السجلات المتداخلة والمصفوفات متعددة الأبعاد. تنفّذ الأعضاء النسخ أو النقل الذي اختارته C++ بترتيب التصريح والعناصر. لا يعيد النقل المولّد تشغيل مهيئات الأعضاء الافتراضية، وتحافظ العمليات البسيطة على قيم المؤشرات المخزّنة. تُهدم المصادر كالمعتاد، ولا تحتاج العمليات المولّدة غير المستخدمة أو البسيطة إلى أجسام مختلقة.

يدعم Core v2 تصريحات `noexcept` و`noexcept(true/false)` القياسية المحسومة و`throw()` في C++17، إضافة إلى استعلامات `noexcept(expression)` الثابتة. تراعي الاستعلامات مواصفات الدوال والهادمات المختارة دون تنفيذ معاملاتها. تظل جميع المعاملات والمواصفات المكتوبة خاضعة لفحص المصدر، بما فيها الشيفرة غير المستخدمة. لا يزال رمي الاستثناءات والتقاطها وفك المكدس والقوالب وSTL الكامل قيد التطوير.

يدعم Core v2 التحميل الزائد العادي للمعاملات كدوال أعضاء أو حرة، بما يشمل الحساب والمقارنة والفهرسة وفك الإشارة والزيادة والكائنات القابلة للاستدعاء وتواقيع الإسناد العامة. يحافظ على الدوال المختارة والمراجع المرتبطة بالكائنات ونتائج الكائنات. تتبع صيغة المعامل ترتيب C++17، وتقيّم المعاملات المنطقية المحمّلة الطرفين. تهيّئ دوال الإسناد الحرة المعاملات من اليمين إلى اليسار ثم تهدمها بالترتيب العكسي. لا تزال القوالب وتخصيص الذاكرة وSTL الكامل قيد التطوير.

يدعم Core v2 أيضاً دوال التحويل العادية للكائنات الحية: التحويلات الضمنية والصريحة للأعداد الصحيحة والتعدادات والمؤشرات، و`bool` الصريح في الشروط، والنتائج المرجعية أو الكائنية. يستدعي كل تحويل دالة العضو المختارة مرة واحدة. تحافظ المراجع على ارتباطها بالكائن الأصلي، وتهيّئ قيم الكائنات المؤقتة وجهتها الفعلية مباشرة. ويحتفظ تحويل المرجع إلى قيمة بعملية النسخ أو النقل المختارة. تتبع مؤهلات const والمراجع وconstexpr وnoexcept قواعد C++17.

يدعم Core v2 الآن الكائنات المؤقتة المستقبلة للاستدعاءات والوسائط المؤقتة العددية أو السجلية الممررة بالمرجع حتى نهاية التعبير الكامل، بما يشمل المنشئات والطرق والمعاملات والتحويلات. لكل تقييم موضع تخزين فعلي، وتحافظ نتائج الكائنات على وجهتها النهائية والمراجع على ارتباطاتها. بعد الاستدعاء وهدم معاملات الدالة، تُهدم المؤقتات بعكس ترتيب إنشائها، بما في ذلك الشروط وتكرارات الحلقات. تُدعَم المصفوفات الفرعية داخل السجلات المؤقتة.

يدعم Core v2 الآن إطالة عمر المؤقتات المرتبطة بمراجع محلية تلقائية عادية، ومنها `const T& r{T{...}}` و`T&& r = T{...}`. تستخدم القيم العددية والتعدادات والمؤشرات والسجلات تخزينًا فعليًا. وتحافظ مراجع الأعضاء أو عناصر المصفوفات على السجل الكامل عندما تقرر قواعد C++ إطالة عمره. تحتفظ التهيئة بالأقواس المعقوفة، مع علامة المساواة أو دونها، بالكائن نفسه. يتبع الهدم نطاق المرجع، بما يشمل الشروط والحلقات والخروج المبكر؛ وتنتهي المؤقتات الأخرى داخل المهيئ مع تعبيرها الكامل. لا تضيف الأسماء المستعارة مالكًا جديدًا، وتحافظ عمليات النسخ والنقل اللاحقة على العمليات المختارة. ما زالت المراجع الساكنة والعالمية والمحلية للخيط والحقول المرجعية والقوالب وSTL الكامل قيد التطوير.

يدعم Core v2 أيضًا المصفوفات المؤقتة المستقلة ثابتة الحجم في الاستدعاءات والتحويل إلى مؤشر والفهرسة والتعبيرات المهملة والمراجع المحلية التلقائية. لكل مصفوفة وجهة فعلية واحدة؛ وتُهيَّأ عناصرها مباشرة وبالترتيب بواسطة القيم العددية والمنشئات والمهيئات الافتراضية المشتركة، دون ملاك إضافيين للعناصر. وعندما تمدد C++ العمر، تحافظ مراجع الصفوف أو العناصر متعددة الأبعاد على المصفوفة الكاملة. تُهدم العناصر بعكس ترتيبها عند نهاية التعبير الكامل أو نطاق المرجع. تبقى العناوين ذات الأنواع وحدود الحجم والتخزين والتوسيع الحالية مطبقة. لا يزال دعم C++/STL الكامل قيد التطوير.

يدعم Core v2 الأصناف الفارغة ذات التخطيط القياسي وكائنات الاستدعاء والتحويل عديمة الحالة. تحتفظ الكائنات الفارغة بحجم ومحاذاة C++ البالغين بايتًا واحدًا، وتخزين مستقل حيث تقتضي اللغة، واستدعاءات المنشئات والعوامل المختارة والهدم المعتاد. تظل عمليات النسخ البسيطة تقيّم معاملاتها، وتُحتسب العناصر الفارغة في المصفوفات والسجلات الحاوية ضمن حدود التخزين. يستخدم NC المُولَّد بايتًا داخليًا وتبقى قائمة حقول المصدر فارغة. لا تزال الوراثة والقوالب وSTL الكاملة قيد التطوير.

يدعم Core v2 التحويل إلى void و`void()` و`void{}` مع أسماء void المستعارة المدعومة والاستدعاءات والإرجاع وتعبيرات الفاصلة والفروع الشرطية. يحافظ تجاهل قيمة يسارية غير volatile على آثار حساب الكائن المستقبِل والفهرس دون قراءة القيمة المخزنة. تظل الكائنات المؤقتة تُنشأ وتُهدم عند نهاية التعبير الكامل الأصلي. لا تُولَّد متغيرات أو قيم void. وتبقى معاملات التعبيرات الثابتة وnoexcept خاضعة للفحص الكامل. لا تشمل هذه المرحلة كائنات volatile والأنواع غير المدعومة والقوالب وSTL الكاملة.

يدعم Core v2 المعاملات الافتراضية للدوال والأساليب ومعاملات الاستدعاء والبواني المدعومة، بما فيها المعاملات اللاحقة في بواني النسخ والنقل المعرّفة من المستخدم. تُحل الأسماء عند التصريح وتُقيّم التعابير عند كل استدعاء يحذف المعامل. تُحفظ هوية المراجع والقيم وأعمارها. تُهدم مؤقتات المعاملات الافتراضية قبل العنصر التالي عند تهيئة عناصر المصفوفة دون مُهيّئ وعند النسخ المولّد للمصفوفة؛ أما المُهيّئات الصريحة فتحافظ على نهاية التعبير الكامل الخارجي. تُفحص القيم الافتراضية حتى إن لم تُستخدم أو استُبدلت بمعامل صريح. لا تزال القوالب وSTL الكاملة غير مكتملة.

## المشروعات متعددة الملفات

اختر وحدات الترجمة صراحةً من قاعدة بيانات التجميع وحدد المجلد الجذري للمشروع. تحلل الواجهة الأمامية المضمّنة كل وحدة على حدة؛ ويتحقق الدمج من التعريفات والربط والأنواع المشتركة والالتزام بقاعدة التعريف الواحد (ODR) باستخدام فحوص محافظة.

```sh
neverc translate --from cpp --profile cpp-project-v1 \
  --project-root "$PWD" --compdb build/compile_commands.json \
  src/a.cpp src/b.cpp --out-dir generated
```

يتكون خرج المشروع من `translated.nc` و`translated.h`. لا تُقبل إلا ترويسات المشروع الواقعة داخل هذا المجلد الجذري. إذا كان للملف عدة إعدادات، فاختر فهرسه الذي يبدأ من الصفر باستخدام `--compdb-entry src/a.cpp=4`. تُحلل أوامر التجميع المحفوظة بوصفها بيانات ولا تُنفذ أبداً.

## دعم محدود للرياضيات بدقة مزدوجة

يضيف `cpp-math-v1` إلى المشروعات نوع `double` والتحويلات والمقارنات الموثقة والتوقيعين الدقيقين `std::fabs(double)` و`std::floor(double)`. يستخدم مجموعة ترويسات Clang 20.1.8 / libc++ 200100 / macOS 15.5 المضمّنة، ويتطلب تحديد هدف macOS 15.0 صراحةً (arm64 أو x86_64). لا تزال العمليات الحسابية العامة بالفاصلة العائمة غير مدعومة. يجب حجب مصائد الاستثناءات وتعطيل تحويل الأعداد دون الطبيعية إلى الصفر؛ اختُبرت أوضاع التقريب القياسية الأربعة.

```sh
neverc translate --from cpp --profile cpp-math-v1 \
  --target arm64-apple-macosx15.0.0 \
  --project-root "$PWD" --compdb build/compile_commands.json \
  src/math.cpp --out-dir generated-math
```

تتحقق الترجمة الرياضية أيضاً من ترويسات NeverC المثبتة وهوية التطبيقات المضمنة وتجري اختبار ربط فعلياً. تستخدم الوحدات المولدة بيئة تشغيل NeverC. مع `-fno-builtin-std` تفشل الترجمة قبل كتابة الملفات فقط إذا احتاجت الشيفرة النهائية إلى تعيينات `fabs`/`floor`. ويمكن مواصلة ترجمة الشيفرة الرياضية التي لا تحتاج إلى هذه التعيينات.

## التحقق والمخرجات

استخدم `--check` بدلاً من خيار إخراج لتنفيذ التحليل والتوليد وفحوص الصياغة وملف الكائن نفسها دون الاحتفاظ بالملفات المولدة. يكتب `--report PATH` تشخيصات منظمة. لا تشغّل عملية الترجمة البرنامج المصدر أبداً.

لا تُستبدل المخرجات أو الملفات الملحقة الموجودة. يتطلب `--out-dir` مجلداً جديداً داخل مجلد أب موجود؛ ويتطلب `-o` مسار `.nc` جديداً. يسجل البيان متطلبات الهدف وبصمات المدخلات والمخرجات وخطوات التجميع؛ وتربط خريطة المصدر الأسطر المولدة بمواضعها الأصلية.

تُسجَّل نتائج CI وفحوص التنفيذ والتثبيت والاختبارات المتخطاة لكل منصة على حدة. يظل macOS arm64 الأصلي وmacOS x86_64 عبر Rosetta بيئتين مختلفتين للتحقق. لا يشمل النطاق المعلن دعم C++/STL الكامل أو الاستثناءات أو القوالب أو السلاسل أو `std::vector`. راجع [مصفوفة الدعم](../../utils/translate-frontends/docs/support-matrix.md)، و[البروتوكول وقواعد الاستعادة](../../utils/translate-frontends/docs/protocol.md)، و[مثال المشروع](../../tests/neverc/Inputs/translate/cpp/project).
