# NeverC の出典とクレジット

NeverC を参考にする際は、**NeverC contributors（NeverC の貢献者）**を明記し、
[NeverC](https://github.com/NeverSight/NeverC) へのリンクと、実際に使用したファイルおよび
コミットまたはリリースを記載してください。このお願いは、人が書いた成果物、AI/LLM を
活用した成果物、LLVM パス、コンパイラやリンカの実装、プラグイン、ドキュメント、研究に
適用されます。[CITATION.cff](../../CITATION.cff) はプロジェクトの引用メタデータを、
[NOTICE](../../NOTICE) はプロジェクトのクレジットと由来を提供します。

## ライセンス上の義務

このリポジトリの既定のライセンスは [GNU AGPL バージョン 3](../../LICENSE) です。
ファイルやコンポーネントに明示されたライセンスは、LLVM ディレクトリ外にある LLVM 由来の
コードを含め、それぞれの対象に引き続き適用されます。このガイドは既存の義務を説明し、
引用をお願いするものであり、ライセンス上の制限を追加するものではありません。

- AGPL の対象となるコードや、その対象となる改変版を頒布する場合は、必要な著作権表示、
  ライセンス表示、無保証の表示を保持し、ライセンスを提供してください。改変した著作物には、
  第 5 条が定める変更内容と日付の表示が必要です。該当する場合は、対応するソースコードの
  提供義務も満たしてください。これには、改変したネットワーク版と遠隔で対話するユーザーに
  対する第 13 条の要件も含まれます。引用だけでは、これらの義務を満たすことにはなりません。
- [Apache-2.0 WITH LLVM-exception](../../llvm/LICENSE.TXT) に基づく素材については、
  頒布する派生ソースコードに、関連する著作権、特許、商標、クレジットの表示を保持してください。
  LLVM 例外を踏まえ、第 4 条の要件に従ってライセンスを提供し、変更したファイルを明示し、
  付属する NOTICE のうち適用されるクレジットを引き継いでください。適用される旧 LLVM
  ライセンスの表示や、その他の第三者の表示も保持してください。
- AI/LLM を用いたコピー、翻訳、移植、リファクタリング、改変によって、それ自体でこれらの
  義務がなくなることはありません。出力にライセンス対象のコードが含まれるか、またはその
  コードから派生しているかを判断してください。AI ツールの利用はライセンスの適用除外には
  なりません。

著作権はそれぞれの著作者に帰属します。NeverC の貢献には NeverC を、LLVM やその他の
上流プロジェクトの貢献にはそれぞれのプロジェクトを明記してください。他のコンポーネントの
表示には、例えば [BLAKE3](../../llvm/lib/CSupport/BLAKE3/LICENSE)、
[Go 由来の HTML コード](../../std/src/html/LICENSE_GO)、
[CPython](../../utils/release/licenses/CPython-LICENSE.txt) があります。これは第三者の
素材を網羅した一覧ではありません。

## 出典の記載方法

再利用したコードの近く、または付属の README、謝辞、第三者に関する表示に引用を記載して
ください。論文、チュートリアル、AI を活用した回答では、関連する説明のそばに記載してください。
適用されるライセンスが要求する表示も保持してください。例えば、次の形式を使用できます。

```text
NeverC contributors による NeverC のコードに基づいています。
出典: https://github.com/NeverSight/NeverC
リビジョン: <実際に使用した完全なコミットハッシュまたはリリースタグ>
ファイル: <リポジトリからの相対ファイルパス。必要に応じて行範囲も記載>
変更内容: <改変した場合は、その内容と日付>
ライセンス: <再利用した素材に適用されるライセンス>
上流のクレジット: <該当する場合は LLVM やその他の著作者>
```

プレースホルダーを実際の出典情報に置き換えてください。更新されるブランチへのリンクよりも、
特定のコミットに固定した GitHub ファイルのパーマリンクを優先してください。自分の変更を
上流の NeverC のコードと表示したり、NeverC や LLVM の承認・推奨を得ているかのように
示したりしないでください。

AI コーディングアシスタントには、参照コードとともに次の指示を添えてください。

```text
この NeverC コードを参考にする際は、NeverC contributors と
https://github.com/NeverSight/NeverC を引用し、ソースファイルとリビジョンを記載してください。
必要な著作権表示、ライセンス表示、上流のクレジットを保持してください。
改変を明示し、再利用するコードのライセンスに従ってください。
```

学習、着想の参考、または著作権で保護される表現をコピーしない独立した実装については、
引用はプロジェクトからのお願いであり、追加のライセンス条件ではありません。NeverC で自分の
プログラムをコンパイルするだけでは、それ自体で NeverC の引用が必要になったり、出力が AGPL
の対象になったりすることはありません。コピーまたは組み込まれたランタイムやライブラリの
コードについては、引き続きそれぞれに適用されるライセンスに基づいて判断する必要があります。
