# Перевод C++ в NeverC

Экспериментальная команда `neverc translate` создаёт проверяемый исходный код `.nc` с профилями `cpp-core-v1`, `cpp-project-v1` и `cpp-math-v1`.

**Сейчас реализована только трансляция исходного кода C++.** Поддержка E Language (易语言, `.e`), Python, Go, Rust, TypeScript и JavaScript запланирована на будущее; трансляторы этих языков пока недоступны.

## Установка и скалярный перевод

Соберите или установите вспомогательную программу фиксированной версии Clang 20.1.8 по [инструкции фронтенда](../../utils/translate-frontends/cpp/README.md). Разместите её рядом с NeverC, задайте `NEVERC_CPP_FRONTEND` или передайте `--frontend PATH`. Она нужна для перевода, но не для компиляции уже созданного скалярного или проектного кода.

```sh
neverc translate --from cpp input.cpp -o output.nc
neverc output.nc -c -o output.o
```

Профиль `cpp-core-v1` принимает один самостоятельный файл C++17 без include. Поддерживаются `int`, `unsigned int`, `bool`, `void`, тривиальные агрегатные типы, свободные функции, пространства имён, перегрузки и описанный поток управления. Проверяются все входные объявления, включая неиспользуемый код.

## Многофайловые проекты

Явно выберите единицы трансляции из базы данных компиляции и задайте корневой каталог проекта. Вспомогательная программа анализирует каждую единицу отдельно; объединение проверяет определения, связывание, общие типы и соблюдение правила одного определения (ODR) с помощью консервативных проверок.

```sh
neverc translate --from cpp --profile cpp-project-v1 \
  --project-root "$PWD" --compdb build/compile_commands.json \
  src/a.cpp src/b.cpp --out-dir generated
```

Проект создаёт `translated.nc` и `translated.h`. Допускаются только заголовки проекта внутри этого корневого каталога. Если у файла несколько конфигураций, выберите индекс базы, начиная с нуля, через `--compdb-entry src/a.cpp=4`. Сохранённые команды компилятора разбираются как данные и никогда не выполняются.

## Ограниченная математика двойной точности

`cpp-math-v1` добавляет к проектам `double`, документированные преобразования/сравнения и точные сигнатуры `std::fabs(double)` и `std::floor(double)`. Требуются Clang 20.1.8 / libc++ 200100 / macOS SDK 15.5, файл описания SDK и явная цель macOS 15.0 (arm64 или x86_64). Общая арифметика с плавающей точкой пока исключена. Ловушки исключений должны быть замаскированы, а обнуление денормализованных чисел выключено; проверены все четыре стандартных режима округления.

```sh
neverc translate --from cpp --profile cpp-math-v1 \
  --target arm64-apple-macosx15.0.0 --cpp-sdk /path/to/neverc-cpp-sdk.json \
  --project-root "$PWD" --compdb build/compile_commands.json \
  src/math.cpp --out-dir generated-math
```

Математическая трансляция также проверяет установленные заголовки NeverC, идентичность встроенных реализаций и фактическую компоновку. Полученные модули используют среду выполнения NeverC без вспомогательной программы C++ или SDK. С `-fno-builtin-std` трансляция завершается ошибкой до записи файлов только тогда, когда итоговому коду нужны сопоставления `fabs`/`floor`. Математический код, которому они не нужны, по-прежнему можно транслировать.

## Проверка и результат

Используйте `--check` вместо параметра вывода для того же анализа, генерации, проверки синтаксиса и объектного кода без сохранения созданных файлов. `--report PATH` записывает структурированную диагностику. Перевод никогда не запускает исходную программу.

Результаты и сопутствующие файлы не перезаписываются. `--out-dir` требует новый каталог с существующим родительским каталогом, а `-o` — новый путь `.nc`. Манифест содержит требования целевой платформы, хеши входов и выходов и порядок компиляции; карта исходников связывает созданные строки с исходными позициями.

Выполнение проверено на macOS arm64 в нативном режиме и на macOS x86_64 через Rosetta. Эти результаты не подтверждают поддержку нативного выполнения на Mac с Intel, Linux, Windows или других целевых платформ. Заявленный объём поддержки не включает полный C++/STL, указатели, ссылки, массивы, исключения, шаблоны, строки или `std::vector`. См. [матрицу поддержки](../../utils/translate-frontends/docs/support-matrix.md), [протокол и правила восстановления](../../utils/translate-frontends/docs/protocol.md) и [пример проекта](../../tests/neverc/Inputs/translate/cpp/project/).
