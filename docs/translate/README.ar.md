# ترجمة C++ إلى NeverC

ينتج الأمر التجريبي `neverc translate` شيفرة `.nc` قابلة للمراجعة عبر `cpp-core-v1` و`cpp-project-v1` و`cpp-math-v1`.

**المتاح حالياً هو ترجمة شيفرة C++ فقط.** دعم E Language (易语言، `.e`) وPython وGo وRust وTypeScript وJavaScript ضمن الخطط المستقبلية؛ ولا تتوفر مترجمات لهذه اللغات بعد.

## الإعداد والترجمة الأساسية

ابنِ أو ثبّت البرنامج المساعد المبني على الإصدار المحدد Clang 20.1.8 باتباع [تعليمات الواجهة الأمامية](../../utils/translate-frontends/cpp/README.md). ضعه بجوار NeverC، أو اضبط `NEVERC_CPP_FRONTEND`، أو مرّر `--frontend PATH`. يلزم للترجمة، ولا يلزم لتجميع مخرجات الترجمة الأساسية أو مخرجات المشروع بعد إنشائها.

```sh
neverc translate --from cpp input.cpp -o output.nc
neverc output.nc -c -o output.o
```

يقبل الملف التعريفي `cpp-core-v1` ملف مصدر C++17 مستقلاً واحداً دون include. يدعم `int` و`unsigned int` و`bool` و`void` والأنواع التجميعية البسيطة والدوال غير الأعضاء ومساحات الأسماء والتحميل الزائد وتدفق التحكم الموثق. تُفحص جميع التصريحات في المدخلات، بما فيها الشيفرة غير المستخدمة.

## المشروعات متعددة الملفات

اختر وحدات الترجمة صراحةً من قاعدة بيانات التجميع وحدد المجلد الجذري للمشروع. يحلل البرنامج المساعد كل وحدة على حدة؛ ويتحقق الدمج من التعريفات والربط والأنواع المشتركة والالتزام بقاعدة التعريف الواحد (ODR) باستخدام فحوص محافظة.

```sh
neverc translate --from cpp --profile cpp-project-v1 \
  --project-root "$PWD" --compdb build/compile_commands.json \
  src/a.cpp src/b.cpp --out-dir generated
```

يتكون خرج المشروع من `translated.nc` و`translated.h`. لا تُقبل إلا ترويسات المشروع الواقعة داخل هذا المجلد الجذري. إذا كان للملف عدة إعدادات، فاختر فهرسه الذي يبدأ من الصفر باستخدام `--compdb-entry src/a.cpp=4`. تُحلل أوامر التجميع المحفوظة بوصفها بيانات ولا تُنفذ أبداً.

## دعم محدود للرياضيات بدقة مزدوجة

يضيف `cpp-math-v1` إلى المشروعات نوع `double` والتحويلات والمقارنات الموثقة والتوقيعين الدقيقين `std::fabs(double)` و`std::floor(double)`. يتطلب Clang 20.1.8 / libc++ 200100 / macOS SDK 15.5 وملف وصف SDK وهدف macOS 15.0 صريحاً (arm64 أو x86_64). لا تزال العمليات الحسابية العامة بالفاصلة العائمة غير مدعومة. يجب حجب مصائد الاستثناءات وتعطيل تحويل الأعداد دون الطبيعية إلى الصفر؛ اختُبرت أوضاع التقريب القياسية الأربعة.

```sh
neverc translate --from cpp --profile cpp-math-v1 \
  --target arm64-apple-macosx15.0.0 --cpp-sdk /path/to/neverc-cpp-sdk.json \
  --project-root "$PWD" --compdb build/compile_commands.json \
  src/math.cpp --out-dir generated-math
```

تتحقق الترجمة الرياضية أيضاً من ترويسات NeverC المثبتة وهوية التطبيقات المضمنة وتجري اختبار ربط فعلياً. تستخدم الوحدات المولدة بيئة تشغيل NeverC دون البرنامج المساعد C++ أو SDK. مع `-fno-builtin-std` تفشل الترجمة قبل كتابة الملفات فقط إذا احتاجت الشيفرة النهائية إلى تعيينات `fabs`/`floor`. ويمكن مواصلة ترجمة الشيفرة الرياضية التي لا تحتاج إلى هذه التعيينات.

## التحقق والمخرجات

استخدم `--check` بدلاً من خيار إخراج لتنفيذ التحليل والتوليد وفحوص الصياغة وملف الكائن نفسها دون الاحتفاظ بالملفات المولدة. يكتب `--report PATH` تشخيصات منظمة. لا تشغّل عملية الترجمة البرنامج المصدر أبداً.

لا تُستبدل المخرجات أو الملفات الملحقة الموجودة. يتطلب `--out-dir` مجلداً جديداً داخل مجلد أب موجود؛ ويتطلب `-o` مسار `.nc` جديداً. يسجل البيان متطلبات الهدف وبصمات المدخلات والمخرجات وخطوات التجميع؛ وتربط خريطة المصدر الأسطر المولدة بمواضعها الأصلية.

اختُبر التنفيذ على macOS arm64 مباشرةً وعلى macOS x86_64 عبر Rosetta. لا تثبت هذه النتائج دعم التنفيذ المباشر على أجهزة Mac بمعالجات Intel أو دعم Linux أو Windows أو أهداف أخرى. لا يشمل النطاق المعلن دعم C++/STL الكامل أو المؤشرات أو المراجع أو المصفوفات أو الاستثناءات أو القوالب أو السلاسل أو `std::vector`. راجع [مصفوفة الدعم](../../utils/translate-frontends/docs/support-matrix.md)، و[البروتوكول وقواعد الاستعادة](../../utils/translate-frontends/docs/protocol.md)، و[مثال المشروع](../../tests/neverc/Inputs/translate/cpp/project/).
