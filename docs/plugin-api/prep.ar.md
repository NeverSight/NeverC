# واجهة إضافات المعالج المسبق

تكشف `PluginPrep.h` عن مخطّطات مستقرّة للرموز (tokens) والمعرّفات والماكرو
والـ pragma وتدفّقات الرموز، دون تسريب أي نوع C++ من NeverC أو LLVM. والمخطّط
المُولَّد `Schema/PluginPrepSchema.inc` هو المرجع المُلزِم للأنواع الرقمية المستقرّة
والفئات والهجاء وقابلية الإنشاء.

## مستويات التوسعة

يمكن للإضافات المشاركة على ثلاثة مستويات:

- أحداث المعالج المسبق للقراءة فقط، الخاصة بالتضمين وتوسيع الماكرو والشروط
  والـ pragma والانتقال بين الملفات؛
- معترِضات مُصنَّفة النوع لمراحل الرمز والتضمين والماكرو والـ pragma والاستعلام عن
  الخصائص؛
- مزوِّد `neverc.prep.build_token_stream` كامل ينشر `TokenStream` مُتحقَّقًا منه.

تدعم مرحلة الرموز الاستبدال والحذف والتوسيع ضمن حدود مضبوطة. ويفرض المضيف ميزانية
التوسيع، ويتحقّق من الهجاء والموضع والرايات وموضع EOF وملكية الرموز قبل نشر أي
استبدال.

## بُناة الرموز

أنشئ الرموز المُصنَّعة عبر `CreateTokenBuilder`، وعيّن حمولة رمز واحدة بالضبط،
وأسنِد موضعًا صالحًا تملكه المهمة، ثم استدعِ `TokenBuilderCommit`. ودمّر البانيَ في
كل المسارات. البانِي بعد الالتزام غير قابل للتغيير، والالتزام الفاشل لا ينشر أي
رمز.

تدفّقات الرموز نواتج مهام متجاورة وغير قابلة للتغيير. ويجب أن يحتوي التدفّق البديل
على رمز EOF ختامي واحد بالضبط، وألّا يتجاوز
`NEVERC_PREP_TOKEN_STREAM_MAX_TOKENS`.

## قواعد المراقبين والمعترِضين

يتلقّى المراقبون بيانات أحداث للقراءة فقط، ولا يمكنهم التأثير في المعالجة
المسبقة. أما المعترِضون فيتّبعون عقد الاستمرار المشترك:

- استدعاء `InvokeNext` مرة واحدة على الأكثر ثم إعادة `CONTINUE`؛ أو
- عدم استدعائه ونشر بديل مُتحقَّق منه.

كائنات الاستمرار وجميع مقابض المعالج المسبق صالحة فقط داخل نطاق ردّ النداء أو
المهمة المُصرَّح به. وإذا لمس خيطٌ أنشأته الإضافةُ تلك القيم، فعليه أن يُنهي
الانضمام (join) قبل عودة ردّ النداء.

## التحقّق

بعد تغيير تعريفات الرموز، شغّل فحوص المخطّط المُولَّد والتغطية:

```sh
python3 utils/plugin-api/gen-prep-schema.py --check
python3 utils/plugin-api/check-coverage.py docs/plugin-api/coverage.json
```

مع `NEVERC_ENABLE_PLUGIN_FUZZERS=ON`، يختبر
`plugin-prep-token-builder-fuzzer` بُناة الرموز المُشوَّهة ومقابض المهام وسعات
الإخراج واستعلامات تدفّقات الرموز.
