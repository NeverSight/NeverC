# API плагинов препроцессора

`PluginPrep.h` предоставляет стабильные схемы токенов, идентификаторов, макросов,
прагм и потоков токенов, не раскрывая C++-типы NeverC или LLVM. Сгенерированная
схема `Schema/PluginPrepSchema.inc` — источник истины для стабильных числовых
разновидностей, категорий, написаний и конструируемости.

## Уровни расширения

Плагин может участвовать на трёх уровнях:

- события препроцессора только для чтения: включения, раскрытия макросов,
  условная компиляция, прагмы и переходы между файлами;
- типизированные перехватчики для фаз токена, включения, макроса, прагмы и
  запроса возможностей;
- полноценный поставщик `neverc.prep.build_token_stream`, публикующий проверенный
  `TokenStream`.

Фаза токенов поддерживает ограниченные замену, удаление и раскрытие. Хост
соблюдает бюджет раскрытия и проверяет написание, позицию, флаги, размещение EOF
и принадлежность токенов, прежде чем опубликовать замену.

## Построители токенов

Создавайте синтезированные токены через `CreateTokenBuilder`, задавайте ровно
одну полезную нагрузку токена, назначайте корректную позицию, принадлежащую
задаче, и вызывайте `TokenBuilderCommit`. Уничтожайте построитель на каждом пути
выполнения. Зафиксированный построитель неизменяем, а неудачная фиксация не
публикует токен.

Потоки токенов — это непрерывные неизменяемые артефакты задачи. Замещающий поток
должен содержать ровно один завершающий токен EOF и не может превышать
`NEVERC_PREP_TOKEN_STREAM_MAX_TOKENS`.

## Правила для наблюдателей и перехватчиков

Наблюдатели получают данные событий только для чтения и не могут влиять на
препроцессирование. Перехватчики следуют общему контракту продолжения:

- вызвать `InvokeNext` не более одного раза и вернуть `CONTINUE`; либо
- не вызывать его и опубликовать проверенную замену.

Объекты продолжения и все дескрипторы препроцессора действительны только внутри
объявленной области обратного вызова или задачи. Поток, созданный плагином,
обязан завершиться (join) до возврата из обратного вызова, если он касается этих
значений.

## Проверка

После изменения определений токенов запускайте проверки сгенерированной схемы и
покрытия:

```sh
python3 utils/plugin-api/gen-prep-schema.py --check
python3 utils/plugin-api/check-coverage.py docs/plugin-api/coverage.json
```

При `NEVERC_ENABLE_PLUGIN_FUZZERS=ON`
`plugin-prep-token-builder-fuzzer` испытывает некорректные построители токенов,
дескрипторы задач, ёмкости вывода и запросы к потокам токенов.
