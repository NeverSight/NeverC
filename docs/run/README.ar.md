# `neverc run`

يُجمّع برنامج C أو NeverC إلى **ملف تنفيذي مؤقت**، ويشغّله على **المضيف المحلي**، ويُعيد حالة الخروج، ثم يحذف المخرج. سير العمل مشابه عمدًا لـ `go run`.

عندما تحتاج إلى الاحتفاظ بالملف الثنائي أو توزيعه أو تصحيحه، استخدم استدعاء المترجم المعتاد (`neverc ... -o output`).

## الصيغة

```text
neverc run [خيارات المترجم] file.c [file2.nc ...] [وسائط البرنامج...]
neverc run [وسائط المترجم...] -- [وسائط البرنامج...]
```

`neverc run --help` يعرض أيضًا ملخصًا مدمجًا.

## تحليل الوسائط

يقسّم `neverc run` الوسائط إلى **استدعاء مترجم** و**وسائط برنامج** اختيارية بإحدى قاعدتين.

### التقسيم الافتراضي (بأسلوب Go)

1. امسح من اليسار إلى اليمين حتى أول وسيط ينتهي بـ `.c` أو `.nc` ولا يبدأ بـ `-`.
2. **كل ما يصل إلى نهاية سلسلة `.c`/`.nc` المتتالية (شاملًا)، مع ما قبل أول مصدر** يذهب إلى المترجم.
3. **كل ما بعد** السلسلة يذهب إلى `argv` للبرنامج المؤقت.

أمثلة:

```bash
neverc run -O2 -fbuiltin-string hello.c
neverc run -O2 main.c helper.nc -- --verbose two words
neverc run -DGENERATED=.c -O2 main.c argument
```

ملاحظات:

- يُعامل `.c` و`.nc` فقط كمصادر run. العلامة `-DGENERATED=.c` تبقى لدى المترجم.
- مصادر متعددة تُجمَّع في ملف ثنائي مؤقت واحد، كالربط متعدد الملفات العادي.

### فاصل `--` صريح

عندما يحتاج المترجم إلى وسائط **بعد** قائمة المصادر (علامات الربط، مدخلات غير مصدرية، `-x c -`، إلخ)، ضع `--` بين ذيل المترجم ووسائط البرنامج:

```bash
neverc run hello.c helper.o -lm -- arg.c -x
neverc run hello.c -O1 -- x
```

كل ما قبل `--` يُمرَّر إلى `neverc` (مع `-o <temp>` داخلي). كل ما بعد `--` يصبح وسائط للبرنامج.

## السلوك وقت التشغيل

| الموضوع | السلوك |
|---------|--------|
| مجلد العمل | يعمل البرنامج المؤقت في **المجلد الحالي** |
| البيئة | يرث البيئة الحالية (`PATH`، المتغيرات المُصدَّرة، إلخ) |
| الإدخال/الإخراج القياسي | stdin/stdout/stderr متصلة بالعملية المؤقتة |
| حالة الخروج | عند النجاح، رمز **البرنامج**؛ عند فشل التجميع، رمز **المترجم** دون تشغيل البرنامج |
| الملفات المؤقتة | الملف التنفيذي داخل `neverc-run-*`؛ يُحذف المجلد بعد التشغيل. يُبلَّغ عن فشل التنظيف بشكل منفصل. |

## أمثلة

```bash
neverc run -O2 -fbuiltin-string hello.c
neverc run -fbuiltin-string greet.c -- Alice "two words"
neverc run -O2 main.c util.nc -- --port 8080
neverc run app.c extra.o -lm -- --config prod.json
```

## القيود والتحذيرات

- **تنفيذ على المضيف فقط.** قد تنجح علامات الترجمة المتقاطعة (`-target ...`) في التجميع، لكن الملف المؤقت يُشغَّل دائمًا محليًا.
- **لا مخرج دائم.** يُحذف الملف الثنائي بعد الانتهاء — استخدم `neverc ... -o out` للتصحيح.
- **نفس toolchain الخاصة بـ `neverc`.** الأمر يعيد استدعاء نفس ملف `neverc` الثنائي.
- **مصادر `.nc`.** نفس قواعد `.c`؛ امتدادات NeverC تُطبَّق تلقائيًا.

## أوامر ذات صلة

| الأمر | متى تستخدمه |
|-------|-------------|
| `neverc file.c -o out` | الاحتفاظ بالملف الثنائي، الترجمة المتقاطعة، سكربتات البناء |
| `neverc build` / `neverc make` | بناء مشروع بـ `neverc.toml` |
| `neverc run --help` | ملخص مدمج |
